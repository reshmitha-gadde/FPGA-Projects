FPGA Projects 🚀

A collection of FPGA-based digital design projects using Verilog HDL.

Hardware Platform

- Digilent Basys 3
- Artix-7 FPGA

Tools

- Xilinx Vivado
- Verilog HDL

Projects

1. LED Blinking
2. Half Adder
3. Full Adder
4. Seven-Segment Display
5. Digital Counter
6. 4-bit ALU

Learning Objectives

- Understand FPGA architecture.
- Develop digital circuits using Verilog.
- Learn RTL design and simulation.
- Implement designs on FPGA hardware.
